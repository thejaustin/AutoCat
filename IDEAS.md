# Local Ideas List - UI/UX Enhancements

This file tracks UI/UX ideas that are less focused on AI and more on refining the core launcher experience.

### 1. Refined Home Screen Edit Mode
- **Concept:** A more intuitive and visual way to edit the home screen.
- **Features:**
    - Shrink items and show a grid background when in "Edit Mode."
    - Display a `+` button in empty cells to directly add apps/widgets.
    - Enable a multi-select mode to move, resize, or folder multiple items at once.

### 2. Advanced Folder Display Modes
- **Concept:** More than just a grid of icons.
- **Features:**
    - **Folder Cover:** First app in the folder is the cover. Tap opens the app, swipe opens the folder.
    - **Mini-Drawer:** Folder opens as a small, scrollable list that hovers on the home screen.
    - **Icon Stacking:** Folder preview uses a more organic "pile" of icons instead of a rigid grid.

### 3. "At-a-Glance" Widget Builder
- **Concept:** Let users build their own At-a-Glance widget.
- **Features:**
    - Settings screen with draggable components (Date, Weather, Battery, Calendar, Music, etc.).
    - Users can arrange components and choose visual styles.

### 4. Dynamic Grid Resizing
- **Concept:** Fluidly change home screen density without losing your layout.
- **Features:**
    - When changing grid size, intelligently reflow icons and widgets to fit the new grid, preserving relative positions.

### 5. Gesture Canvas
- **Concept:** A dedicated, invisible "Gesture Pad" widget for custom shape-based gestures.
- **Features:**
    - Draw a "C" to open Camera, "W" to call someone, etc.
    - Customizable shapes and actions.

### 6. Wallpaper-Aware Theming Options
- **Concept:** Deeper integration with the wallpaper beyond just color extraction.
- **Features:**
    - **Text Shadow/Outline:** Automatically add for readability on bright wallpapers.
    - **Blur Dock/Folders:** Frosted glass effect using wallpaper colors.
    - **Focus Dimming:** Dim/blur wallpaper when a folder is open.
