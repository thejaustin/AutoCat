# Security Policy

The latest version of AutoCat is the only supported version.

| Version        | Supported          |
| -------------- | ------------------ |
| dev-latest     | :white_check_mark: |
| 15-autocat     | :white_check_mark: |

## Reporting Security issues

We appreciate your efforts to responsibly disclose your findings and will make every effort to
acknowledge your contributions.

To report an issue, please file a [security advisory](https://github.com/thejaustin/AutoCat/security/advisories/new)
or contact the maintainer via GitHub.

We'll endeavor to respond quickly, and will keep you updated throughout the process.
