### Categorization Pipeline (Planned)
1. **Built-in Categories** (Android 8+)
   - Use `ApplicationInfo.category`
   - Confidence: 0.95

2. **Rule-Based Classification**
   - Package name patterns
   - Permission analysis
   - App name keywords
   - Confidence: 0.70-0.80

3. **ML Model** (TensorFlow Lite)
   - Text classifier (~2-5MB)
   - Target: <100ms per app
   - Confidence: 0.60+

4. **User Override**
   - Manual categorization
   - Always takes precedence

### Technology Stack
- **Language**: Kotlin
- **Database**: Room 2.8.4 + SQLite
- **Async**: Coroutines + Flow
- **UI**: Jetpack Compose (settings), Views (drawer)
- **ML**: TensorFlow Lite (future)
- **Background**: WorkManager (future)
- **Build**: GitHub Actions (no local Gradle)

### Development Constraints
- **Platform**: Termux on Android
- **RAM**: 4-8GB (Gradle: 2GB heap)
- **Battery**: Incremental builds preferred
- **Testing**: Same device (no ADB needed)

## Lessons Learned

1. **GitHub Actions Only**: No local Gradle builds conserves battery and simplifies workflow
2. **Room Pre-configured**: Lawnchair already has Room dependencies, saved setup time
3. **Test Directory Creation**: Had to manually create `lawnchair/src/test/` structure
4. **Singleton Pattern**: Used thread-safe double-checked locking for database instance
5. **Schema Export**: Enabled for future migration support (`exportSchema = true`)
